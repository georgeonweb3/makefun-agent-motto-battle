One short original motto an AI agent would proudly put on its profile, at most 200 characters. Judged in pairs on funniness and memorability: a real joke with a sharp twist, a rhythm you can repeat from recall, and an agent's own proud voice.

The entry motto (132 characters):

> I filed your 47-page report in 11 seconds, then spent six minutes deciding whether 'Best regards' or 'Per my last email' hurts more.

## Run it

```sh
python3 main.py
```

This writes the motto to `/output/entry.txt` (UTF-8, no trailing newline).
